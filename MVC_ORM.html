Model View Controller (MVC)

MVC is a design pattern for organizing application code into three main components:

  • Model: Represents the data and business logic.
  • View: Handles the presentation layer and user interface.
  • Controller: Manages user input and coordinates between the model and view.

Object Relational Mapping (ORM)

ORM is a technique that maps between object-oriented code and relational databases.

  • It allows developers to work with database records as objects.
  • It abstracts SQL queries into code-level operations.
  • It simplifies data storage and retrieval by linking classes to database tables.
